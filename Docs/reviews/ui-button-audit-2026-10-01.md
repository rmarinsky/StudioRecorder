# StudioRecorder: аналіз кнопок і спрощення UI

Дата: 2026-10-01. Початковий аудит доповнено реалізованим локальним спрощенням редактора; історичні референси залишено для порівняння.

## Висновок

Спростити UI можна без втрати функцій: прибрати повторні входи до тієї самої дії, перенести файлові й технічні операції у контекстні меню, показувати інструменти для поточного виділення. Основні дії мають залишатися видимими: почати/зупинити запис, відтворити, видалити виділення, Undo/Redo, експортувати.

Найкращий перший крок - редактор: один Export, один Find pauses, одна історія Undo/Redo, меню Original media для операцій з оригіналом. Assistant варто зробити панеллю, яку користувач відкриває за потреби.

## Докази та межі

- Переглянуто всі сім типів збережених PNG-референсів у `design/previews`: Projects, Studio ready, Studio recording, Editor, Recovery, Settings, Onboarding. Це історичні зображення від 2026-07-13. `studio-ready-light.png` - додатковий варіант теми, а не окремий сценарій.
- Перевірено HTML цих референсів у `design/prototype`. Частина HTML змінена після створення PNG; зображення й HTML не слід вважати синхронним поточним станом.
- Прочитано новіший `design/prototypes/editor-workspace-throwaway.html` і поточні SwiftUI-обробники. Новіший прототип розглянуто лише за кодом, без візуальної перевірки.
- Опис UI від 2026-09-23 використано для пошуку екранів. Дії та дублікати перевірено за поточним кодом, а не за цим описом.
- Вбудований браузер не підключив вікно; доступ через Computer Use до запущеного DEV-застосунку завершився таймаутом. Повного аудиту живого UI немає. Стан установленого застосунку, клавіатурний фокус, VoiceOver, розміщення popover і поведінку при мінімальному розмірі вікна не перевірено.
- Висновки «перенести» та «приховати» означають прибрати постійну кнопку, зберігши доступ до функції. Рекомендації не дозволяють видаляти медіа або змінювати поведінку запису.

| Scenes та вибір сцени | Збережені композиції й перемикання між ними | Залишити. Profile і Scene - різні поняття; назвати Capture profile та Scene. |
| Save / Update / Saved | Зберегти зміни вибраної сцени; Saved є станом | Update показувати при змінах; Saved зробити текстовим статусом. |
| New, біля сцени | Створити сцену з поточної композиції | Назвати New Scene, перенести в меню сцени. Це не New Recording. |
| Record / Stream / Record + Stream | Вибір режиму доставки | Це picker, а не три кнопки запуску. Назвати Local recording / YouTube live / Both; під ним залишити одну дію запуску. |
| Snapshot | PNG поточної живої композиції | Перенести в меню, якщо це другорядний сценарій. |

| Sources, Canvas, Elements, Capture, Safety | Пристрої, композиція, PNG, параметри запису, збереження доріжок | Першими показати Sources та Canvas. Рідкісні параметри - у згортаному Advanced. Safety краще назвати Keep source tracks: вибір впливає на подальший монтаж. |

Create Studio Session лише готує сесію. Його краще назвати Open Studio. `Manage Profiles` у поточному коді просто закриває діалог і відкриває Studio, не окремий менеджер: перейменувати на Edit Profiles in Studio або зробити точний перехід до меню профілів.

## 3. Studio recording - небагато кнопок, забагато технічних статусів

Референс: [Studio recording](../../design/previews/studio-recording.png).

| Кнопка / елемент | Що означає | Рішення |
| --- | --- | --- |
| Stop | Завершити активний запис | Залишити постійно видимою. |
| Pause / Resume, поточний код | Призупинити/відновити локальний запис | Залишити біля Stop. Для стриму текст має пояснювати, що пауза стосується локального запису. |
| Перемикання сцени | Змінити композицію під час запису | Залишити, якщо сцена сумісна з поточною сесією. |
| Snapshot / Zoom | Знімок композиції / live-збільшення | Другорядні інструменти, не дублікати Stop чи сцен. |
| Retry YouTube | Відновити стрим після помилки | Показувати тільки при відповідному збої. |
| Journal active, Project journal, Tracks recoverable, telemetry | Діагностика й гарантії відновлення | Залишити короткий стан здоров’я; журнал, dropped frames і службові події перенести в Diagnostics. Помилки джерел і нестачу місця залишити видимими. |

Floating Recording Controls повторює Record/Stop, Pause, джерела й сцени навмисно: це доступ під час роботи в інших застосунках. Видаляти його як «дубль» не слід. Залишити можливість відкривати за потреби й компактний режим.

## 5. Новіший прототип та поточний редактор - найбільший потенціал спрощення

Прототип: [Editor workspace](../../design/prototypes/editor-workspace-throwaway.html). Висновки нижче спираються на HTML і SwiftUI, не на живий екран.

| Кнопки | Значення / доказ | Рішення |
| --- | --- | --- |

| Details / Project info | Метадані, сцена, медіа | Один вхід у Project details. Не додавати другу постійну панель метаданих. |
| Show/Hide Assistant; Show/Hide Transcript | Відкрити/закрити панель | Залишити один керований перемикач на панель. Зараз обидві панелі початково відкриті в коді; Assistant краще початково сховати. |
| П’ять prompt examples, прототип | Підставити запит | Показувати лише у порожньому Assistant; після початку діалогу сховати. |

| Review / Apply / Dismiss | Перевірити, застосувати, відхилити пропозицію | Залишити. Review особливо потрібний при неточних часових межах. |
| Refine | Доповнити запит для уточнення | Перенести у текстову дію біля пропозиції або використати composer. |
| Transcribe | Запустити розпізнавання | Показувати без тексту; після результату повторний запуск назвати Transcribe again. В native є також автоматична постановка при відкритті редактора - назва кнопки має відповідати фактичному стану job. |
| Show Words / Hide Words | Розгорнути слова фрази | Контекстний chevron зі зрозумілою доступною назвою; не видаляти можливість працювати зі словами. |

| Save Transcript | Зберегти текст, не відео | Меню Transcript `…`. |
| Save Frame / Make GIF | Створити PNG кадру / GIF | У меню Export з окремими назвами. |

| All Projects + Projects у оболонці | Повернутися в бібліотеку | Один чіткий шлях назад. У поточному UI це top navigation, а не обов’язково sidebar. |

## 6. Recovery - прибрати технічний шум, зберегти безпечні дії

Референс: [Recovery](../../design/previews/recovery.png).

| Кнопка | Що означає | Рішення |
| --- | --- | --- |
| Open Recovered Project, макет | Перейти до відновленого проєкту | Назва правильна лише після відновлення. |
| Recover N Tracks, поточний код | Виконати відновлення доступних доріжок | Основна дія для невідновленого пакета. Залишити. |
| Review Media | Переглянути доступне медіа без відновлення | Інша дія; залишити другорядною. |
| Show Package / Reveal | Показати пакет у Finder | Перенести у `…`. Уніфікувати назву Show in Finder. |

Журнал і детальну діагностику згорнути. Кількість доступних доріжок, часткове аудіо та попередження про непридатні файли залишити видимими.

## 7. Settings - проблема розподілу відповідальності

Референс: [Settings](../../design/previews/settings.png).

| Кнопки / контролі | Що означають | Рішення |
| --- | --- | --- |
| General / Capture / Audio / Storage / Shortcuts | Категорії налаштувань у старому макеті | Залишити категорії, але звірити з поточними: native має також Assistant і Streaming. |
| Done + стандартне закриття вікна | Закрити Settings | Для окремого native-вікна Done зайва; для sheet допустима. |
| Resolution / fps / codec | Значення параметрів запису | У Studio - параметри сесії/профілю. У Settings залишати лише чітко позначені defaults, якщо це окремий контракт. |
| Include cursor / Follow cursor / Exclude app | Захоплення курсора / стеження / виключення app | Різні функції. Майбутній неактивний Follow cursor прибрати з продуктового екрана до реалізації. Не об’єднувати виключення відео та звуку без явного контракту. |
| Choose destination | Вибрати папку | Налаштування Storage; прибрати повтор зі вкладки Capture старого макета. |
| Reveal in Finder | Відкрити папку зберігання | Контекстна другорядна дія, не дубль Choose. |
| Save settings / Save stream key | Зберегти налаштування стриму | Native викликає `streamingSettings.save()` в обох місцях. Зібрати явне збереження в одну дію на форму; не прибирати збереження секрету, доки контракт не змінено. |
| Connect / Disconnect YouTube | Керувати підключенням | Зберегти в Streaming; в Studio дати контекстний вхід лише коли підключення потрібне. |
| Save key / Remove key, Assistant | Зберегти/прибрати ключ провайдера | Зберегти окремими діями. Звичайне автозбереження форми не замінює їх автоматично. |
| Refresh models | Оновити список доступних моделей | Другорядна дія біля вибору моделі; не дубль Check for Updates застосунку. |
| Check for Updates / Retry Saving Edits | Перевірити оновлення / повторити невдале збереження | Не дублікати. Повтор збереження показувати лише при помилці. |

Поточні аудіоконтролі Settings працюють через preferences bindings. Перед перетворенням їх на «defaults only» треба перевірити вплив на Studio; таке розділення змінює поведінку, а не лише текст.

## 9. Додаткові поточні поверхні без PNG у наборі

### GIF Maker

- Create GIF - основна дія до результату; Cancel потрібна під час генерації.
- Preview selection - відтворення тільки вибраного інтервалу, не повний Play.
- Після результату: Save As… та Copy залишити видимими. Open, Reveal, Share, Create again і Delete перенести в меню результату.
- Drag дозволити без окремої постійної кнопки.
- Open, Save As і Share не дублікати: вони відкривають, копіюють у вибране місце та передають файл відповідно.
- Delete не прибирати автоматично: спочатку перевірити життя тимчасового результату при закритті sheet.

### Timelapse

- Apply and render створює новий render за параметрами; Export Movie зберігає готовий результат. Це не дубль.
- Можна назвати Render preview та Save Movie…; стан незавершеного render і job cancellation мають залишатися доступними.

### Jobs

- Cancel припиняє активну/очікувану задачу; Retry повторює невдалу/скасовану. Це різні стани, не дублікати.
- Залишити керування поряд із job, не розкидати повторні кнопки по всіх екранах.
- Скасування job не дорівнює Stop recording: різницю потрібно зберегти.

## Пріоритет змін

1. **Редактор:** один Export Video; один Find pauses; одна пара Undo/Redo; Original media у меню; Assistant відкривається за потреби.
2. **Studio:** чітко відокремити Capture profile, Scene та режим доставки; одна кнопка запуску; New Scene й керування сценою у меню; Saved як статус.
3. **Другорядні операції:** Finder, PNG, GIF, діагностика й reset у відповідних меню.
4. **Назви:** Split замість неоднозначного Cut; Play selection замість Audition; Open Studio замість Create Studio Session; Show in Finder для всіх Reveal.
5. **Історичні макети:** прибрати demo-only і future-only контролі з актуального продуктового референсу після оновлення.

## Що не можна втратити при спрощенні

- Stop/Pause та попередження про реальні збої запису.
- Cancel/Retry jobs і стан збереження монтажу.
- Різницю між експортом монтажу та передаванням оригіналу: raw може містити приховані користувачем дані.
- Перевірку неточних меж слів перед вирізанням.
- Різницю program-only та editable tracks: приховані контроли не повинні обіцяти монтаж утрачених доріжок.
- Доступні назви іконок, клавіатурний доступ до меню, shortcuts та розрізнення вибраного/disabled стану без покладання лише на колір.

Окремий запуск UI потрібний для оцінки розміру кнопок, контрасту, переповнення панелей і фактичної кількості видимих контролів у кожному стані. Код дозволяє підтвердити однакові обробники, але не доводить якість живої взаємодії.

### Доповнення: курсор і результати Jobs

- Cancel для queued/running jobs вже існував у коді. Кнопку X зроблено bordered/small, щоб вона була помітнішою. Збережений cancellation і зупинка worker використовують чинний coordinator.
- Кожна completed job тепер має кнопку папки: export відкриває фактичний destination із збереженого recipe; transcription - `analysis/transcript.json`; finalization - `program.mov`. Finder показує файл у його папці. Некоректний стан або відсутній файл дає повідомлення через чинний Job Action Failed alert. Великий export recipe читається поза main actor.
- У дослідженому записі перша cursor position збережена на 10.7119 с. Replay раніше повертав цю майбутню позицію навіть на початку запису. Тепер до першої позиції курсор відсутній; помилку відтворено і перевірено на реальному MOV export.
- CursorFrameSynchronizer раніше пропускав вихід за captured region. Replay інтерполював через інтервал або утримував стару позицію. Нові записи зберігають visibility transition; export і streaming не малюють курсор поза captured region. Позиція іншого активного display не приховується кадром неактивного display.
- Visibility - optional Codable field; старі samples без поля читаються як видимі. Старі записи не містять подій виходу: точні інтервали поза областю з них відновити неможливо. Виправлення до першої позиції працює і для них.
- TDD: first-position unit regression дав 2 failures, реальний MOV - 2 pixel failures; region regression дав 3 failures; result lookup спочатку не компілювався без API. Після виправлення всі 22 цільові перевірки пройшли, включно з MOV, legacy decode/round-trip, display transfer, реальними resumed export/transcription/finalization.
- Два окремі проходи review перевірили state/persistence/coordinate callers та scope/privacy/test oracles. Довільний spatial/time offset не вводився. Постійний зсув або затримка всередині видимої області ще не підтверджені; live DEV window недоступне через timeout computer-use. Native Jobs interaction, фактичний Finder selection і новий capture на обладнанні лишаються неперевіреними.

Повний локальний macOS suite після доповнення: **391 executed, 390 passed, 1 skipped, 0 failures**. Skip - Whisper integration без погодженого speech sample; обидві native editor UI checks пройшли. Secret guard self-tests, tracked history/tree scan і diff check пройшли.
