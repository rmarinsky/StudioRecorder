# Studio Recorder 0.1.0

The first release with signed in-app updates through Sparkle.

- Record screen, camera, microphone, and system audio in a native Studio workspace.
- Keep recoverable projects and editable source tracks, or retain a composed program movie.
- Edit picture and sound together without changing retained originals.
- Export video, PNG snapshots, and GIFs.
- Check for updates from the app menu or Settings. Update installation waits for recording, streaming, and media processing to finish.

Requires macOS 26 or later on Apple Silicon. Install this first release manually in Applications; later releases can update it in place. Development builds use a separate app identifier and do not receive production updates.

Local transcript word boundaries can require waveform review. Managed YouTube requires configured application OAuth credentials. Long streaming and hardware-failure recovery validation remains in progress; treat streaming as a preview capability.
